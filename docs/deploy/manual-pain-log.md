# 수동 배포 불편 기록

EC2 수동 구축([manual-ec2.md](manual-ec2.md))을 하면서 그때그때 적는다. 시작 · 끝 시각은 Task 8의 "수동 배포 시간"이 된다.

- 시작 시각: 2026-11-26 06:29
- 끝 시각: 2026-11-26 10:40 (06:29~06:50, 10:20~10:40 두 번에 나눠 작업)
- 총 걸린 시간: 약 41분 (작업한 시간만)

| 시각 | 한 일 | 걸린 시간 | 불편했던 점 | 다시 하면 자동화할 것 |
|------|-------|-----------|-------------|------------------------|
| 06:29~06:50 | VPC · 서브넷 · 인터넷 게이트웨이 · 라우팅 · 보안 그룹 · 키 페어 · EC2 · 탄력적 IP | 약 21분 | 콘솔 화면을 여러 번 옮겨 다니며 이름과 설명을 매번 손으로 입력했다 | 네트워크와 서버를 코드로 정의해 한 번에 만든다 (Terraform) |
| 10:20 무렵 | SSH 접속 | - | 작업 장소의 공인 IP가 바뀌어 SSH가 막혔다. 접속이 응답 없이 멈춰서 원인을 알기 어려웠고, 보안 그룹을 손으로 고쳤다 | 22번 포트를 열지 않는 접속 방식(Session Manager)을 쓰거나, 허용 IP를 변수로 둔다 |
| 10:20~10:40 | 패키지 설치 · DB · 코드 · 환경 파일 · 마이그레이션 · 적재 · 서비스 등록 · Nginx · HTTPS | 약 20분 | 명령을 문서에서 하나씩 복사해 붙였다. 서버가 재시작되면서 `/tmp`에 올려 둔 스냅샷 파일이 사라져 다시 올렸다 | 설치를 스크립트나 컨테이너 이미지로 만든다. 배포 파일은 재시작에 지워지지 않는 곳에 둔다 |

## 잘 된 것

- 서버를 중지 · 재시작해도 탄력적 IP 덕분에 주소가 유지됐다.
- 재부팅 뒤 API · MCP · Nginx · PostgreSQL이 모두 자동으로 다시 떴다.
