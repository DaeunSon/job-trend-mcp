# 스킬 매칭률 — 비스킬 태그 필터 전후 (2026-10-14 재측정)

`scripts/measure_skill_match.py` 로 같은 raw 공고를 필터를 끄고 / 켜고 두 번 파싱해 비교했습니다.
저장은 하지 않고, 측정 중 alias 후보 등록도 막았습니다.

- 매칭률 = 표준 스킬 91개로 해석된 태그 / 추출된 태그 (태그 단위)
- 필터 전: `skill_noise_filter.is_skill_noise` 를 끄고 파싱 · 필터 후: 지금 파서 그대로
- 사람인 · 잡코리아 · Adzuna 처럼 본문에서 사전 매칭으로 스킬을 뽑는 사이트는 정의상 매칭률이 높고,
  필터를 쓰지 않는 사이트(원티드 · 점핏 등)는 전후가 같습니다.

## 해석

- 필터 효과는 비정형 태그를 그대로 받는 해외 API(Arbeitnow · Remotive)와 잡코리아에서 크다.
  8월 데이터는 이 사이트 비중이 높아 전체 효과가 컸고(+16.8%p), 10월 데이터는 국내 내부 API
  비중이 높아 작다(+1.4%p).
- 인턴 당시 기록된 53.1% → 80.6% 는 측정 스크립트와 결과 파일이 남아 있지 않아 같은 조건으로
  재현하지 못했다. 위 수치는 필터 단독 효과이며, 당시 alias 보강(A · C 단계)이 함께 반영됐는지는 알 수 없다.
- 점핏(64.9%)처럼 필터와 무관하게 낮은 사이트는 미매칭 태그를 alias 로 보강해야 한다 (#3).
