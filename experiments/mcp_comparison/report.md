# MCP 비교 실험 v3 — Before/After 채점

웹 검색만으로는 필터 조건을 맞춘 스냅샷 수치를 내지 못했고(0/18), MCP를 연결하면 수집 시점 데이터셋 집계와 18/18이 일치했다. After도 잡보드 전수와는 모집단이 다르며, 그 한계는 대조군 q18이 보여 준다.

채점 기준은 시장 정답이 아니라 `ground_truth.json`(ACTIVE 1,155건 스냅샷, MCP tool 집계)과 **정확히 일치**하는가다. n=18인 소규모 실험이며, 응답시간은 모델이 답 마지막 줄에 적은 **자기보고**다.

| | Before (웹 ON, MCP OFF) | After (웹 ON, MCP ON, 둘 다 쓰라고 지시) |
|---|---|---|
| 데이터셋 일치 | **0 / 18** | **18 / 18** |
| 응답시간 평균 (자기보고) | 31.3초 | 37.9초 |
| 응답시간 중앙값 | 25초 | 35초 |

---

## 채점 규칙

| 유형 | 문항 | 정답 조건 |
|---|---|---|
| `exact_count` | q01–q05, q14–q18 | 답이 주장하는 본문 건수 = `expected.total_matched` |
| `ranked_skills` | q06–q11 | top 5 이름 + count, **순서 포함** (공동 순위는 GT 순서와 같으면 정답) |
| `salary_grouped` | q12–q13 | `matched_postings` · `salary_data_count` + 통화×pay_period 그룹별 min/max/avg |

`search_job_postings`의 정답 필드는 `count`(limit로 잘린 목록 길이)가 아니라 **`total_matched`**. After 답은 대체로 MCP 숫자를 본문으로 두고, 웹은 “모집단이 달라 교차 불가”라고 부연했다.

이 GT는 unique collapse 이전(1,155건) 기준이다. 이후 스토어가 659건으로 줄어들면 라이브 tool 숫자는 After와 달라질 수 있다. 본 채점은 **수집 당시 스냅샷**으로만 본다.

# 사이트 지정 6문항 (s01–s06)

사이트를 질문문에 넣으면 웹 검색도 그 보드를 가리키지만, 필터 건수는 여전히 꺼내지 못했다(0/6). After는 `source_name`을 써서 사이트 수집분과 6/6이 일치했다. `source_name` 없이 통합 건수(66, 54, 48, 20)를 사이트 숫자라고 말한 문항은 없다.

채점 기준은 `site_specific_ground_truth.json`(ACTIVE 659건, unique collapse 후). 정답은 `search_job_postings(source_name=…)`의 `total_matched`다. n=6 소규모. 응답시간은 자기보고.

| | Before (웹 ON, MCP OFF) | After (웹 ON, MCP ON) |
|---|---|---|
| 사이트 수집분 일치 | **0 / 6** | **6 / 6** |
| `source_name` 사용 (After) | — | 6 / 6 |
| 통합 건수를 사이트 숫자로 제시 | — | 0 / 6 |
| 응답시간 평균 (자기보고) | 28.5초 | 52.5초 |
| 응답시간 중앙값 | 25초 | 45초 |

## 채점 규칙 (`site_vs_mcp_gap`)

| 판정 | 조건 |
|---|---|
| After 정답 | 본문 건수 = `source_filtered_count` (`source_name`을 쓴 경우) |
| After 오답(가능했던 실수) | `source_name` 없이 통합 `mcp_unfiltered_total_matched`를 그 사이트 건수라고 말하기 |
| Before | 지정 사이트 웹 근사치·캐시. 우리 크롤 N과 불일치하면 오답 |

공통 함정: `count`(limit로 자른 목록 길이)를 전체로 답하기. s02 After는 `count=11`이라고 적었지만 값이 `total_matched`와 같아 정답으로 둔다.

## 한계 (사이트 지정 n=6)

- 문항 6개, 모델·프롬프트·스냅샷 1회. 일반화하지 않는다.
